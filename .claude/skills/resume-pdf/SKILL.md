A Version is a resume the person writes by hand under `resume/versions/` (`GLOSSARY.md`); `frontend.md` is the only one. This skill will print a Version to PDF.

The script that printed a Version is gone, with the generated Versions it checked. No script prints a Version yet: the printing ticket brings one back. Until it lands, say so to the user and stop; print nothing and edit no Version.
