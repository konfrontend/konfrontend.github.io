# CV workspace

The source of one person's CV. Every bullet lives in the master; a version is copied from it for one application.

## Language

**Master**:
The single document every version is copied from: contact, summaries, skills and one entry per project.
_Avoid_: draft, pool, resume source

**Project**:
One job, engagement or personal project, with one entry in the master and one project file.
_Avoid_: company, client, position

**Project file**:
The full record of one project: its bullets grouped by theme, closed by its keywords line.
_Avoid_: pool, inventory, log

**Theme**:
A named group of bullets inside a project file, such as "Browser extension".
_Avoid_: section, category, area

**Bullet**:
One line of a project's work, in a project file or in a version.
_Avoid_: highlight, point, achievement

**Keywords line**:
The list of technologies and practices a project covers, closing its project file.
_Avoid_: skills line, tech stack, tags

**Version**:
One CV document made from the master: the general version behind the public PDF, or one tailored to an application.
_Avoid_: draft, template, CV file

**Application**:
One job applied to, with its tailored version, PDF and cover letter.
_Avoid_: job, posting, opportunity

**Tracker**:
The list of applications and where each stands.
_Avoid_: pipeline, log, spreadsheet
