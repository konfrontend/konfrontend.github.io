# CV

The CVs of one web developer: the Master and the Versions made from it. The Profile terms (Project, Story, Bullet, Skill, Naming) are the autotriage plugin's.

## Language

**Master**:
The single document of the Profile every Version is copied from: contact, summaries, skills and one entry per Project.
_Avoid_: draft, pool, resume source

**Version**:
One CV document made from the Master: the general Version behind the public PDF, the frontend Version, or one tailored to a Job.
_Avoid_: draft, template, CV file
