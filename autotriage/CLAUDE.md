# autotriage

A plugin of the professional-profile repo (PP, the repo root one level up). The root `AGENTS.md` describes the whole repo; this file covers the plugin.

## Agent skills

### Domain docs

Single-context: `GLOSSARY.md` beside this file names the plugin's terms, the Profile model among them. The plugin's ADRs live in `docs/adr/` at the PP root (`../docs/adr/`) since the merge.

## Plugin layout

This folder is the Claude Code plugin (`.claude-plugin/plugin.json`; `.claude-plugin/marketplace.json` is kept for the day it is ported out again as its own marketplace). `skills/<category>/<skill>/SKILL.md`, every skill listed in `plugin.json`: `route/` holds `route` (entry) and one skill per State, `profile/` holds `setup`, `skills` and `tracker`. `catalogue/` holds the portable Families, Flags, voice, verify Checks, Letter templates, the Candidate artifact contract, and the Skill ledger rules; `scripts/` the Guard, the Verdict arithmetic, the hooks, `schemas/`, and `vendor/deps.mjs` (generated by `npm run vendor`, never edited by hand); `hooks/hooks.json` registers the hooks.

The plugin holds no user data. The Profile and the Candidates live in PP's `data/` (ADR 0004; `scripts/paths.mjs` resolves it from the project the session runs in). Develop against PP with `claude --plugin-dir autotriage` from the repo root. Bump `version` in `plugin.json` on every release, or installed copies do not update.
