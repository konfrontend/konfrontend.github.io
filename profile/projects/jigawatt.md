# Jigawatt Solar

## Description
SaaS for solar dealers and installers: from interactive 2D/3D design and energy modeling to CRM.

## Keywords
`TypeScript`, `React`, `Zustand`, `React Three Fiber`, `WebGL`, `GLSL`, `three.js`, `shadcn/ui`, `Tailwind CSS`, `GSAP`, `WebAssembly (WASM)`, `Azure Functions`, `Azure Blob Storage`, `Microsoft SQL Server`, `Google Maps API`, `Web Workers API`, `Service Worker API`, `Computer-Aided Design (CAD)`, `Progressive Web Application (PWA)`, `Computational Geometry`

### CAD Engine
Engineered the 3D CAD modeling system that solar dealers and installers use to design an installation. Shipped 80+ features, including procedural 3D mesh generation, real-time 3D topology editing, REST and Google Maps API integrations.

### Shade Simulation
Authored a WebGL shade simulation in a Web Worker that shows solar dealers a roof's yearly energy loss to shadows from trees and other obstructions. The result appears in 40 ms to 15 s as a GPU-generated heat map on the 3D model, without freezing the editor.

### Public Wiz
